# ECG–sleep-apnea multimethod protocol

Dated 2026-11-15, before new model comparisons. Finite first execution budget: eight wall-clock hours; unfinished trials remain pending, not failures. This is a historically exposed development database, not a new pristine test. No ECG–echo datasets enter this program. Original files and poster analyses are read-only.

## Scope and data gates
Apnea-ECG ECG/annotation pairs are checked against the second local copy by SHA256; original headers, byte length, WFDB checksums, finite signals, minute spacing and A/N symbols are audited. Current annotation coverage takes precedence over outdated web prose. c05/c06 have documented overlap and share a group. Duplicate waveform hashes and overlapping signal blocks are audited. Complete subject identifiers are unavailable: primary groups conservatively block equal sex/age/height signatures plus known overlap and detected duplicate content. Demographic blocks are NOT verified identities and can both merge people and miss repeated people. Generalization is to held-out proxy groups, not proven independent patients. All historically used records retain their exposure status.

Official reference AHI, age, sex, height and weight are transcribed from the provider's additional-information table with source provenance. AHI is not apnea-minute percentage. Original AHI denominator details require source review; no new claim that it uses verified total sleep time. Clinical BMI is weight/(height/100)^2. Do not infer sleep time or reconstruct clinical AHI from minute counts.

## Tasks and permitted information
Primary prediction comparison: regularized structured ECG logistic regression versus restrained gradient boosting for current one-minute annotation detection, grouped outer AUROC with paired group-bootstrap difference. Labels include apnea/hypopnea minutes, not obstruction-specific disease. ECG over [t,t+1 minute) predicts annotation t; this is end-of-window retrospective detection.

Forecasting is distinct: ECG ending at t+1 predicts target minute t+2, with a 60-second gap and 60-second target horizon. State forecasting evaluates every eligible period. Annotation-defined new-transition forecasting additionally restricts eligibility to current observed minute N and defines target as target A AND immediately preceding minute N. The intervening minute is used only to define the future target, never as a predictor or eligibility filter. It is not a second-accurate event onset. No future AHI or annotation-derived burden enters ECG-only models. Never mix persistence with new transitions.

Current detection and state forecasting compare one- and two-minute lookbacks as a prespecified sensitivity, not a post-hoc winning window. Neural screening initially uses one-minute ECG only. Classical selection is inner grouped AUROC, identical outer rows across models. AHI prediction uses whole-night ECG summary features, clinical covariates alone and combined; primary AHI metric MAE, with RMSE, bias and calibration. Severity thresholds 5/15/30 are secondary; unsupported class counts are reported, not concealed.

## Validation and search
Three common outer folds, two inner grouped folds where label support permits; grouped splits immutable after integrity gates. Inner training only fits imputation, scaling, learned representations, normal transitions, readouts and thresholds. Hyperparameter budgets: two settings per structured family (logistic/ridge, RF, HGB, RBF SVM/SVR); tree as an interpretable reference. SVM limited deterministic training-only sample of 4000 windows for feasibility, same outer evaluations. No final winner is re-tuned on outer outcomes. Each model/configuration is reported. Neural family screening: CNN, ResNet, TCN, CNN–GRU, at most two configurations, <=200k parameters, 40-epoch ceiling, patience8, meaningful loss improvement0.002. ReLU/AdamW fixed. Max6000 fitting windows sampled deterministically without label selection; evaluation uses all eligible outer windows. Same inner fitting/monitor groups per fold; early stopping and configuration choice use monitoring only. Fixed selected-epoch refit uses outer-training groups; final evaluations independent of early stopping. Fixed first configuration receives three seeds if runtime permits; average seeds, never pick luckiest. This limited neural selection uses one designated inner holdout, not full two-inner-fold tuning; report that computational difference explicitly.

Representations: train-only standardized feature PCA and compact waveform AE/VAE/masked reconstruction encoders, same ridge/logistic readout and input patients. Representation pretraining excludes outer ECGs. Latent K-means/GMM k2/3 selected by training-only silhouette/support/stability, not AHI or apnea labels. Report subject/record identity concentration and quality associations; no biological subtype claim. Unsupervised input normalization fitted only in relevant training groups. Neural reconstruction losses and downstream performance reported separately.

## Causal information and QC
Every forecasting feature is computed from a bounded ECG crop ending at cutoff. Causal SOS filtering starts within that crop; no whole-night normalization, bidirectional filter, future interpolation, future RR endpoint or supplied full-record QRS annotation enters forecasting. Peak detection uses only the crop, with at least 5 valid RR, finite nonflat signal; accepted RR 0.3–2.0s, successive change <=30% for feature analysis, record removed fractions. No claims that frequency-domain HRV or entropy is reliable in one-minute windows; omit them. Provided QRS annotations are audited separately as unaudited machine detections, not beat-type ground truth. Signal coverage>=95%, <=20% rejected RR, otherwise window excluded. WFDB physical units preserved; waveform neural inputs downsample within crop to25Hz and train-fold normalization only. This loses high-frequency QRS detail and must not be called a pure morphology model.

## Residual physiology and geometry
Configurations (L,g)=(2,1),(2,0),(2,2),(5,1) minutes. tA first A of bout, tN first subsequent N. Pre=[tA-g-L,tA-g); post=[tN+g,tN+g+L). Require all pre/post AND buffer minutes N, complete labels, finite accepted features. Only A/N bouts, no inferred physiological onset. Select nonoverlapping apnea windows chronologically per record per configuration. Controls: N-only pseudo-events with same bout-length separation and geometry, chosen within recording by closest permitted pre-feature/time distance, no replacement; all intervals N. No control matching on post state. Outcome ranges never used to force594/570 counts. Train ridge and small nonlinear MLP to predict standardized post features from pre and elapsed time on outer-training pseudo-events only; primary residual deviation is L2 norm divided by training cross-fitted normal residual SD. Compare pre, post, ordinary change and conditional residuals on same real/pseudo pairs. Report held-out normal calibration first. Direction PCA fits only normal training residuals; never apnea-fitted PCA for the primary normal-deviation claim. Primary real-minus-control residual norm difference uses group bootstrap; geometry/model family multiplicity Holm. RMSSD is excluded from residual predictor/state panel and evaluated only as contemporaneous same-window secondary change, not causal injury. Recovery +0,+2,+4 minutes is secondary, requires N and no reuse of invalid windows, and reports changing support. Respiratory/SpO2 comparisons contingent on verified alignment; otherwise pending.

## Statistics and interpretation
AUROC, AP with prevalence, Brier, calibration intercept/slope, sensitivity/specificity at inner-OOF Youden threshold, pooled and equal-group summaries. Alarm threshold frozen from inner data; contiguous positive minutes form one alarm, 2-minute suppression, false alarm per recorded eligible hour (not sleep hour). Group bootstrap500 repeats for conditional metrics and paired differences, not training variability. AHI MAE/RMSE/bias/slope, thresholds and 4category counts. Holm within prespecified family; no whole-program novelty claim from minimum P. Report unavailable metrics under one-class bootstrap samples. Training seeds address optimizer variation, not independent sample size.

## External freeze
UCDDB role: external evaluation only. Use PSG .rec modifiedV2 ECG, never unsynchronized Holter. Audit EDF start, event times across midnight, respiratory types O/C/M/HYP, exclude PB/CS without explicit counted event, sleep stages0wake/6artifact/7indeterminate excluded for sleep-only evaluation. Exact bin overlap and wake eligibility must be locked from actual schema before model results. ECG polarity is header/provider convention; do not select sign from label performance. AHI requires event-count denominator and verified sleep duration; otherwise use provider reference only. Freeze weights, preprocessing, threshold and external eligible record manifest before evaluation. Missing network/EDF access blocks external evaluation, not primary work. SHHS/MESA require approved local access; no access solicitation or credentials inspection.

## Stop rule
Deadline or STOP sentinel triggers checkpoint at the next safe boundary. Incomplete folds are never pooled as complete nested validation. Finishing within eight hours does not establish study completion. Manuscript reports only completed patient-data analyses, labels administrative placeholders, and preserves negative findings.
